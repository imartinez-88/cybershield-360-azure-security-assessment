# **CyberShield-360 Azure Security Assessment**

Enterprise cloud security assessment focused on Microsoft Azure Key Vault security architecture, NIST SP 800-171 compliance, threat modeling, RBAC hardening, audit logging, and incident response.

## Topics Covered

- Azure Key Vault
- Microsoft Entra ID
- NIST SP 800-171
- FedRAMP
- STRIDE Threat Modeling
- OWASP Threat Dragon
- RBAC Hardening
- Audit Logging
- Azure Monitor & Sentinel
- Incident Response Analysis
- Midnight Blizzard Breach Analysis

## Key Areas

### Risk Assessment
- Compared NIST SP 800-30 vs OCTAVE Allegro
- Evaluated cloud security governance
- Assessed sensitive data classification

### Threat Modeling
- STRIDE-based threat analysis
- Azure Key Vault authentication workflow
- OAuth token abuse scenarios
- Privilege escalation analysis

### Security Hardening
- Azure RBAC implementation
- MFA enforcement
- Audit log monitoring
- Log Analytics integration
- Least privilege architecture

### Compliance Focus
- NIST SP 800-171
- FedRAMP alignment
- FIPS 140-2 considerations
- Government contractor cloud controls
